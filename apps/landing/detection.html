Architecture limits

The 5% that requires a kernel extension.

Hound operates entirely in user space using macOS public APIs. ~95% of the MITRE ATT&CK framework is detectable from here. The remaining 5% requires Apple's Endpoint Security Framework, which needs kernel-level entitlements from Apple and a paid developer account. These are post-beta targets.

Process injection

Memory injection, dylib injection, and task_for_pid attacks are not visible from user space. A compromised process that injects code into another process leaves no file system or process-spawn trace that Hound can observe.

T1055

Rootkits

By definition, rootkits hide themselves from user-space observers. Kernel-level hooking or direct filesystem manipulation is invisible to process monitors and FSEvents.

T1014

Traffic signaling

Deep packet inspection and network traffic content analysis require a Network Extension. Hound detects beaconing patterns via connection metadata but cannot inspect TLS payload content.

T1205

Direct volume access

Attacks that read raw disk blocks bypass the filesystem entirely. These are detectable only at the block device layer, which requires kernel entitlements.
