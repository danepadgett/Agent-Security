Requirements

System requirements.

Operating system macOS 12 Monterey or later
Architecture Apple Silicon (M1, M2, M3, M4) and Intel x86-64
Memory ~16 MB RSS at runtime
CPU overhead <1% on Apple Silicon during normal operation
Disk ~50 MB installed (agent + runtime logs)
Required permission Full Disk Access
Optional permission Accessibility (for keylogging detection)
Network Not required for core detection. Optional for AI explanations.

Installation

Up and running in four steps.

01

Open the installer

Double-click Hound.dmg. Drag Hound.app to your Applications folder. Eject the disk image.

02

Grant Full Disk Access

Hound needs Full Disk Access to monitor the directories where threats appear — Downloads, LaunchAgents, SSH keys, and others. Without it, file monitoring is limited.

System Settings → Privacy & Security → Full Disk Access → toggle Hound on.

03

Launch Hound

Open Hound from Applications. The agent starts in Simulation Mode — it detects, correlates, and alerts, but does not kill processes or quarantine files. Review the incident feed for a few days before switching to Live Mode.

The Hound icon will appear in your menu bar. The agent runs automatically on login.

04

Enable Live Mode when ready

Once you've reviewed the incident feed and added any trusted processes to the whitelist, switch to Live Mode in Settings. In Live Mode, Hound will kill high-confidence malicious processes and quarantine suspicious files.

Settings → Agent Mode → Live Response

Permissions

Why Hound needs these permissions.

Hound requests the minimum permissions needed to monitor your Mac. It never requests access to iCloud, Contacts, Calendar, or any personal data.

Full Disk Access

Required

Allows Hound to read files in protected directories: Downloads, Desktop, LaunchAgents, LaunchDaemons, ~/.ssh, ~/.aws, and others. Required for file monitoring and magic bytes detection.

System Settings → Privacy & Security → Full Disk Access

Accessibility

Optional

Enables detection of keylogging attempts (T1056.001). Without this, Hound will not detect processes that attempt to register global keyboard event listeners. Core detection is not affected.

System Settings → Privacy & Security → Accessibility

Verification

Verify the download.

Always verify the SHA-256 hash of any security software before running it. Open Terminal and run:

# Verify the download
shasum -a 256 ~/Downloads/Hound.dmg
# Expected output:
a3f8c2d1e4b7f9a0c3d6e8b2f5a7c9d0e3f6a8b1c4d7e9f2a5b8c1d4e7f0a3b6 Hound.dmg

If the hash does not match, do not run the file. Contact the Hound team.
