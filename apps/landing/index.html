Sensor layer

What Hound actually watches.

Four independent sensor subsystems. Each generates atomic signals. The detection engine evaluates those signals against 165 behavioral tests.

File System

Watches 11 directories using macOS FSEvents API (push-based, not polling). Detects file creation, permission changes, quarantine attribute changes, and magic bytes mismatches — executables disguised as PDFs or images.

~/Downloads ~/Desktop LaunchAgents ~/.ssh ~/.aws BTM database
~18 microseconds mean per tick

Process Monitor

Uses sysinfo kernel API — no subprocess spawning. Captures PID, parent PID, command, arguments, and executable path. Classifies processes as system, browser, interpreter, user app, or unknown. Flags dangerous parent-child relationships.

interpreter abuse LOLBin execution masquerading double extension
~35 milliseconds mean per tick

Network Monitor

Polls active connections via lsof. Tracks per-PID connection history across ticks to detect C2 beaconing patterns: repeated connections to the same external IP at regular intervals. Apple and Google IP ranges suppressed.

C2 beaconing external connections upload patterns exfiltration
~17 milliseconds mean per tick

Persistence Monitor

Watches LaunchAgents and LaunchDaemons via FSEvents. Polls crontab for modifications. Monitors the BTM (Background Task Management) database. Detects login hook installation via com.apple.loginwindow defaults.

LaunchAgents LaunchDaemons crontab login hooks BTM database
~8 milliseconds mean per tick

Why Hound

Not your typical antivirus.

Traditional AV fails because it compares files against known-bad lists. Hound fails attackers by watching what programs actually do.

Traditional AV

Signature-based detection misses everything novel

Known signatures can only catch threats that have already been seen. Zero-days, fileless attacks, and obfuscated payloads pass right through. By the time the database is updated, the damage is done.

Enterprise EDR

Enterprise tools cost thousands per seat

CrowdStrike and SentinelOne are genuinely excellent. They're also priced for organizations with dedicated security teams. A freelancer or a 10-person company can't access this category.

Hound

Behavioral detection. Free. On your machine.

Hound catches attack patterns regardless of what the malware looks like. curl piped into bash is suspicious. A PDF that becomes an executable is suspicious. Hound understands this. No subscription required.

Getting started

Running in under 5 minutes.

No account required. No cloud signup. No subscription. Download, install, and it's watching.

Download the installer

Download the .dmg, drag Hound to Applications. Double-click to launch.

Privacy & trust

Everything stays on your Mac.

Hound is designed for people who take their privacy seriously. No telemetry. No account. No cloud.

No data leaves your machine

All detection, correlation, and response happens locally. Your file paths, process names, and incident history never touch a server. The AI explanation feature is optional and only activates when you explicitly ask with an API key you provide.

No account required

Download and run. There is no sign-in, no email capture, no license key. Hound will never lock you out or require renewal.

Simulation Mode by default

Hound defaults to Simulation Mode on install. It detects and alerts but never kills a process or quarantines a file without your explicit opt-in. You review before it acts.

Hard guardrails, always on

Even in Live Mode, Hound will never kill a system process, a browser, or anything in /System. Never quarantine a PDF, image, or document. The guardrail system is load-bearing and cannot be disabled.
